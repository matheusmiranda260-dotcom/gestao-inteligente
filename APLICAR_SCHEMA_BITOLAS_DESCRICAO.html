⚙️ Atualização do Banco: Descrição de Produtos

Permite descrições detalhadas (ex: rolo 2000kg vs 200kg) e não mistura Fio Máquina com CA-60

1 Copiar Script SQL de Atualização

Clique no botão abaixo para copiar o script que adiciona a coluna description e permite variações de produtos com a mesma bitola:

-- 1. Adiciona a coluna description na tabela stock_gauges caso não exista ALTER TABLE public.stock_gauges ADD COLUMN IF NOT EXISTS description TEXT; -- 2. Remove a restrição UNIQUE restritiva antiga que impedia ter a mesma bitola com descrições diferentes (ex: rolo 2000kg vs rolo 200kg) ALTER TABLE public.stock_gauges DROP CONSTRAINT IF EXISTS stock_gauges_material_type_gauge_key; -- 3. Atualiza os registros existentes sem descrição com um valor padrão amigável UPDATE public.stock_gauges SET description = material_type || ' ' || REPLACE(gauge, '.', ',') || 'mm' WHERE description IS NULL OR description = '';
✅ Script copiado para a área de transferência!
2 Executar no Supabase SQL Editor

1. Acesse o painel do seu Supabase.

2. Clique em SQL Editor no menu lateral esquerdo.

3. Cole o código copiado e clique em Run (Executar).
