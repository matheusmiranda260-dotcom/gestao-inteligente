⚙️ Schema dos 5 Porta-Rolos da Treliça

Este script cria a tabela trelica_spool_stands no Supabase para sincronização em tempo real dos 5 porta-rolos (Superior, 2 Senozoides e 2 Inferiores) entre celulares dos operadores e o Quadro PCP.

✓ SQL Copiado para a Área de Transferência!
Instruções rápidas:
  1. Clique no botão acima para copiar o script SQL;
  2. Acesse o seu Supabase Dashboard;
  3. No menu lateral esquerdo, clique em SQL Editor;
  4. Cole o código (Ctrl+V) e clique no botão verde RUN;
  5. Pronto! As 2 Treliças terão os 5 desbobinadores sincronizados ao vivo.
